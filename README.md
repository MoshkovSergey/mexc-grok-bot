# MEXC Grok-like Bot

Учебный/исследовательский trading bot scaffold для MEXC Spot API.

## Важно

- Проект не гарантирует прибыль.
- По умолчанию работает в **paper mode**.
- Live trading включается только через `ENABLE_LIVE_TRADING=true`.
- Перед live-торговлей проверьте:
  - официальные требования MEXC к точности количества/цены;
  - лимиты API;
  - комиссии;
  - риски частичных исполнений;
  - юридические/налоговые аспекты в вашей юрисдикции.

## Архитектура

- **backend**: Go HTTP API, бот-движок, MEXC REST client, PostgreSQL persistence.
- **frontend**: React dashboard для наблюдения за equity, позицией, сигналами, рисками.
- **db**: PostgreSQL для свечей, состояния бота, ордеров, снапшотов equity, risk events.
- **docker**: локальный запуск всех сервисов.

## Настройки (Settings)

Панель **Settings** в UI позволяет менять без рестарта контейнера:

- `SYMBOL` — торговая пара (например, `BTCUSDT`, `KASUSDT`);
- `INTERVAL` — таймфрейм свечей (белый список приходит с сервера из `GET /api/settings`);
- `FAST_PERIOD` / `SLOW_PERIOD` — периоды SMA-стратегии;
- `POLL_SECONDS` — частота опроса биржи;
- `MAX_POSITION_PCT` / `MAX_DRAWDOWN_PCT` — риск-лимиты;
- `PAPER_EQUITY` — стартовый капитал для будущего сброса состояния;
- `LIVE_ORDER_VALUE_LIMIT` — лимит одного live-ордера.

Значения хранятся в таблице `bot_settings` (PostgreSQL) и перечитываются ботом на
каждом цикле. Переменные окружения задают только **дефолты при первом создании** строки
настроек; после этого источником истины является БД.

### Поведение при смене пары

- **paper**: открытая позиция автоматически закрывается по последней известной цене
  старой пары, кэш зачисляется, `peakEquity` перевзвешивается на новый all-cash equity
  (иначе старый пик вызвал бы ложный drawdown-stop). Событие пишется в `paper_orders`
  с пометкой `auto-close on symbol change`.
- **live**: смена пары при ненулевой позиции **запрещена** (HTTP 409). Реальные активы
  не продаются без явного решения оператора.
- Если для закрытия paper-позиции нет ни свежих свечей в памяти, ни истории в БД,
  запрос отклоняется (HTTP 409), чтобы не угадывать цену.

### Live-режим

`ENABLE_LIVE_TRADING` намеренно остаётся только в `.env` и не переключается из UI:
включение боевой торговли из неаутентифицированного браузера небезопасно. В панели
live-статус отображается как read-only бейдж.
